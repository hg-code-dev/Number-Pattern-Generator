# Number Pattern Function

## Description

This project was completed as part of the FreeCodeCamp Python curriculum.

The goal of this project was to practise fundamental Python programming concepts by creating a function that generates a sequence of numbers from 1 to a specified positive integer. During this project, I developed my understanding of:

- Creating and using functions
- Input validation with `isinstance()`
- Conditional statements (`if`)
- `for` loops and the `range()` function
- String concatenation and formatting
- Returning values from functions
- Writing cleaner, more reliable code through error handling

The function checks that the input is a valid integer greater than zero before generating the number pattern, helping to reinforce the importance of validating user input.

## Example

```python
number_pattern(5)
```

**Output:**

```text
1 2 3 4 5
```

## What I Learned

Through this project, I gained practical experience with Python control flow, data validation, and string manipulation. It also helped me understand how to build functions that handle both valid and invalid inputs, making code more robust and user-friendly.
